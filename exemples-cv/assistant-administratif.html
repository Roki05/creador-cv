Exemple de CV assistant(e) administratif(ve)

Le CV d'un assistant administratif doit inspirer confiance : organisation, rigueur et aisance avec les logiciels. Regardez comment cet exemple précise chaque mission avec des chiffres et cite les outils que l'on retrouve dans les offres d'emploi.

Utiliser cet exemple dans l'éditeur Gratuit et sans inscription. Remplacez les informations par les vôtres et téléchargez le PDF.

Conseils pour votre CV d'assistant administratif

  1. Citez vos logiciels. Excel, Sage, SAP, Cegid, Pennylane… Ce sont les mots-clés que filtrent le plus les logiciels de recrutement (ATS).
  2. Chiffrez vos missions. Combien de factures, de clients ou de fournisseurs vous suiviez chaque mois. Les chiffres rendent le CV crédible.
  3. Racontez vos améliorations. Dématérialiser l'archivage, réduire les erreurs ou les délais : c'est ce qui vous distingue des autres candidats.
  4. Précisez votre niveau sur Excel. Plutôt que « Excel avancé », donnez des exemples : tableaux croisés dynamiques, RECHERCHEV, macros.
  5. Relisez-vous deux fois. Pour un poste administratif, une faute d'orthographe dans le CV pèse double.

Compétences et mots-clés recherchés par les recruteurs

  • Excel avancé (tableaux croisés dynamiques
  • RECHERCHEV)
  • SAP
  • Sage
  • Facturation
  • Gestion des fournisseurs
  • Classement et archivage
  • Accueil

Ne gardez que celles que vous maîtrisez vraiment et reprenez les mots exacts de l'offre d'emploi : c'est ce que recherchent les logiciels de recrutement (ATS).
